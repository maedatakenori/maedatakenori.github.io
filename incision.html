Series 2: Execution Protocol — Incision

Specification Archived; Execution Withheld

Overview

概要

A set of generated specifications for cutting and reassembling an existing drawing. Each output preserves the source image, incision map, colour-bar coordinates, and seed value.

既存の細密画を切断し、再構成するために生成された仕様群。各出力は、元画像、切断図、カラーバーの座標、シード値を保存する。

The Procedure

手続き

The generator calculates edge-to-edge cuts across the image and assigns independent positions for colour bars. The same hand that produced the drawing would be required to carry out the cuts.

ジェネレーターは画像を端から端まで横断する切断線と、独立したカラーバーの位置を算出する。描画を制作した同じ手が、その切断を実行することを要求される。

Non-execution

非実行

The commands were not carried out. The source drawing remains intact, while the generated maps and the dated declaration preserve the point at which execution was withheld.

命令は実行されなかった。元の細密画は損なわれず、生成図と日付を持つ非実行宣言が、実行を留保した時点を保存する。

What exists / 現存するもの

The source drawing, four generated execution maps, their seed values, and the dated declaration of non-execution. The work is the preserved relation between an issued command and an intact surface.

元の細密画、四つの実行図、そのシード値、日付を持つ非実行宣言。作品として保存されるのは、発行された命令と、損なわれていない表面との関係である。
